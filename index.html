Quick Start

Recommended workflow

  1. Open the QS Main Ribbon tab or type QSMENU.
  2. Set Project Info.
  3. Load BOQ CSV with QSLOAD.
  4. Select a BOQ item.
  5. Run Full Takeoff or Selected Takeoff.
  6. Create Measurement / Measurement Table.
  7. Run Validate / Auto Check.
  8. Review Project Health.
  9. Use Snapshot, Revision / VO and Export tools as needed.

Key commands

CommandPurpose
