Privacy Policy

Effective date: 20 September 2026

Overview

QS CAD Engine is a desktop AutoCAD add-on published by El Sayed Azam.

Data collection

The current desktop release is designed to operate locally inside AutoCAD and does not intentionally transmit drawing data, BOQ data, project information, measurements, or user files to an external server.

Local data

Project metadata, snapshots, approvals and change-log information may be stored locally in the active drawing and/or exported by the user to local files such as CSV reports.

Internet communication

The current release does not require an online account and does not intentionally send project content over the internet.

Third-party services

No third-party analytics or advertising services are included in the current release.

User responsibility

Users are responsible for protecting their own drawings, BOQ files, exported reports, backups and other project information.

Future changes

If future versions add cloud services, telemetry, analytics, licensing servers or external integrations, this policy will be updated before that version is published.
